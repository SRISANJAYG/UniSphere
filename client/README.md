# UniSphere frontend

React + Vite student interface. See the [project README](../README.md) for setup, features, API information, and the [demo video](https://drive.google.com/file/d/1-Ef4gs58XdXCOWbjk75B__Ot6uxsasW3/view?usp=sharing).

Run `npm install`, then `npm run dev`. Use `npm run build` for a production build.
